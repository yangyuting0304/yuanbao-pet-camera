# 新机器上手清单（换电脑时照着走一遍）

> 目标：换一台 Windows（或 macOS）电脑，**半天内**能改代码、跑测试、装真机。
> 全程大约 30~60 分钟下载 + 20 分钟配置。
>
> 交接文档：给 AI 助手看 [../AGENTS.md](../AGENTS.md)，给人看 [../HANDOVER.md](../HANDOVER.md)。

## 0. 先把仓库拿到手

```bash
git clone https://github.com/yangyuting0304/yuanbao-pet-camera.git
cd yuanbao-pet-camera
git log --oneline -3        # 应该能看到 docs: 新增 HANDOVER.md 交接文档
```

> 本机直连 github.com 偶尔会 `schannel SSL handshake failed`：
> 可改用镜像 `git clone --depth 1 https://gitclone.com/github.com/yangyuting0304/yuanbao-pet-camera.git`，
> 或用 `codeload.github.com` 下 zip。

## 1. 工具链

| 工具 | 版本（本次开发用） | 怎么装 | 备注 |
|------|-------------------|--------|------|
| Flutter | **3.44.7**（stable） | <https://docs.flutter.dev/get-started/install/windows> | 自带 Dart 3.12.2；装完加进 PATH |
| Android Studio | Ladybug 或更新 | <https://developer.android.com/studio> | 自带 JDK 与 Android SDK |
| JDK | 17 | Android Studio 自带即可 | 本机 `java` 不在 PATH，是正常的：Android 构建走 Gradle wrapper |
| Android SDK | API 34+ | Android Studio 的 SDK Manager | |
| Chrome | 任意 | | 只有跑 Web 版才需要 |
| Xcode | 16+ | 仅 macOS | **Windows 上不能出 ipa**，iOS 走云构建 |

装完 Flutter 后确认：

```bash
flutter doctor -v
flutter --version      # 应为 3.44.7
```

## 2. 拉依赖 + 跑测试（验证环境没问题）

```bash
flutter pub get
flutter test -j 1      # 245 个测试，应全过
```

> `-j 1` 是必须的：并发编译在部分机器上会 OOM，报
> `The Dart compiler exited unexpectedly`（这不是代码问题）。

## 3. 本机专属文件（不入库，要自己生成）

| 文件 | 作用 | 怎么来 |
|------|------|--------|
| `android/local.properties` | Android SDK 路径 | Flutter 会自动生成；或手写 `sdk.dir=C\:\\Users\\<你>\\AppData\\Local\\Android\\Sdk` |
| `ios/Flutter/flutter_export_environment.sh` | iOS 引擎路径 | `flutter pub get` / `flutter build ios` 自动生成 |
| `frontend_env.json` | 云端 AI 代理地址 | **已入库**，clone 就有（只有三个 URL，无密钥） |
| `cloud_functions/*/.env` | 云函数真实密钥 | **不入库**，仓库里只有 `.env.example`；需要时找云端负责人或按 `DEPLOY.md` 重新配置 |

## 4. 跑起来看效果

```bash
# Web（最快，不需要真机）
flutter run -d chrome --web-port=8080

# Android 真机
flutter devices            # 插上手机并开启 USB 调试
flutter run -d <device-id>
```

> Android 首选走项目根 **`build_apk.cmd`**：本项目路径含中文，且 F 盘 exFAT
> 无法创建 junction，脚本会自动镜像到 `C:\yuanbao_build` 构建后回拷。
> 直接 `flutter build apk` 在这台机上会因为路径问题失败。

## 5. 构建 iOS 包（Windows 只能云构建）

`codemagic.yaml` 已配置好，推送后由 Codemagic 出包：

- 触发方式与凭据见 `DEPLOY.md`；
- `ios/Podfile` 里的**照片输出上限补丁**在 `pod install` 时自动生效，
  构建日志里应出现「已把 iOS 照片输出上限压到 12MP」；
- 排查时可用环境变量 `YUANBAO_IOS_PHOTO_CAP=0` 跳过补丁做 A/B。

## 6. 换到 Codex / 其他 AI 助手

1. 在仓库根目录放好 **`AGENTS.md`**（已在仓库里，clone 即有）——
   Codex 会自动读取它，里面是自包含的项目指令与红线。
2. 给助手的开场提示可以直接是：

   > 先读 AGENTS.md 与 HANDOVER.md，再读 TODO.md 的「六、iOS 端待办与决策」。
   > 我要你做的事是：……

3. 提醒助手两件事（AGENTS.md 里也写了）：
   - 改滤镜参数先跑 `tools/filter_lab/preview.dart` 看锐度比，别直接上真机；
   - iOS 闪退要看「拍照诊断日志」，native 崩溃拿不到控制台日志。

## 7. 换机后建议立刻验证的三件事

| # | 做什么 | 期望 |
|---|--------|------|
| 1 | `flutter test -j 1` | 245 全过 |
| 2 | Android 真机拍一张，进「设置 → 拍照诊断日志」 | 能看到 `takePicture.start` 等记录 |
| 3 | iOS 云构建后装机，按宠物模式 → **等 1 秒多** → 按快门 | 不闪退；成片分辨率约 4032×3024 |

## 8. 容易在新机器上踩的坑

| 现象 | 原因 | 处理 |
|------|------|------|
| `flutter test` 报编译器意外退出 | 并发编译 OOM | 加 `-j 1` |
| `flutter build apk` 失败（路径相关） | 中文路径 + exFAT 不能建 junction | 走 `build_apk.cmd` |
| `git push` 报 `fetch first` | 远端有本地没有的提交（**不是网络问题**） | `git fetch origin` → `git log HEAD..origin/main` → rebase |
| `git commit -m "多行中文"` 参数被拆 | PowerShell 引号规则 | 改用 `git commit -F <文件>` |
| 推大文件报 `curl 55` | git 缓冲默认 1MB | `git -c http.postBuffer=524288000 push` |
| iOS 闪退但没有日志 | native 崩溃带走了 Dart 日志 | 设置页「拍照诊断日志」 |
