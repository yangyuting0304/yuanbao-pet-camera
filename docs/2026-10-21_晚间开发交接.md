## 成片平台实现与数据

- Android：Media3 Transformer 1.9.4，H.264/AAC MP4，系统相册导出。
- iOS：AVAssetWriter + AVMutableComposition/AVAssetExportSession；照片逐张复用缓冲，不囤积所有帧；内置字幕合成与音乐循环。
- Web：Canvas.captureStream + MediaRecorder 实际编码，优先 MP4，支持时回退 WebM；WebM补写duration元数据，可用播放器与再次编辑读取时长。浏览器必须支持相关API，并保持前台；不支持时准确报错。
- 系统分享使用 [share_plus 12.0.2](https://pub.dev/packages/share_plus/versions/12.0.2)；Web不能文件分享时下载真实文件，不伪造分享成功。
- 短片 Hive 元数据 + 手机 Documents/short_videos 或 Web IndexedDB 字节箱；列表只留引用，打开/分享时按需读取。Web照片也进入IndexedDB，恢复最新24张；浏览器清站点数据会移除本地内容。
- `prepare_local_photo.dart` 只读编码头获取尺寸，再引擎限尺寸解码，长边不超过960；修复 Web `ImageDescriptor.width` 不支持导致选图失败。新导入会缩图；原始素材仍由用户自己保留。
- 保存顺序为先本地持久化再系统导出，授权拒绝/空间不足时允许重试。云同步失败明确提示，不影响已保存副本。
