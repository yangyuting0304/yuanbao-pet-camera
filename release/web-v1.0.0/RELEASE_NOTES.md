## 部署说明（上线云服务用）

### 本地预览
```bash
cd release/web-v1.0.0
python -m http.server 8092
# 浏览器打开 http://localhost:8092
```
> 重要：必须从本目录起 HTTP 服务（`index.html` 的 `base href=/`）。
> 从父目录起服务会导致资源路径 404 白屏。

### 云静态托管（任选其一）
- **腾讯云 CloudBase / Cloud Studio**：上传 `release/web-v1.0.0/` 整个目录作为静态站点根
- **Vercel / Netlify / GitHub Pages**：根目录指向 `release/web-v1.0.0/`
- **Nginx**：`root` 指向该目录，`try_files $uri $uri/ /index.html`

### 体积
约 432MB（含 170 张种子图 + 字体 + Flutter JS）。
上线前可压缩图片 / 开启 Gzip+Brotli 显著瘦身。

## 已知限制（上线前须知）

1. **相机能力在 Web 端受限**：`相机` 页面与宠物卡右上角相机按钮在浏览器中依赖 `camera` 插件，需 HTTPS + 用户授权，部分桌面浏览器无摄像头。Android/iOS 真机 App 中体验完整。
2. **云端 AI 能力未接**：AI 写真 / 短片剪辑 / 宠物 P 图 路由已建，但云端 API（通义万相 DashScope）需注入 `DASHSCOPE_API_KEY` 才生效，当前为骨架。
3. **相册数据本地化**：种子照片打包在 assets 内，拍照存入分组的逻辑在真机端完整，Web 端为演示态。
