# 元宝拍拍正式图标

工具：内置 imagegen（2026-10-21）。保留生成原图 `app_icon_yuanbao_cat.png`（1254×1254 RGB）。

设计要求：金元宝造型的可爱猫咪为主体，融入相机镜头元素，金黄色主色、简洁清晰、小尺寸易辨识、无文字。温暖圆润的橘金猫咪与金元宝轮廓结合，双眼有神，胸前/爪间相机镜头；纯净暖黄色背景，主体集中、安全留白、精致立体但保持图标清晰。

平台资源由 `python tools/generate_app_icons.py` 从原图生成。iOS 所有尺寸均为不透明正方形，不预画圆角；Android 多密度图标与 Web 普通/maskable 图标同步更新。原图保持高分辨率，不把平台缩略图当母版。
